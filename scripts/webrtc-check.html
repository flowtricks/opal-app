Local WebRTC camera check

Select Opal Studio Camera, then Start. The left video is the camera source; the right is the video encoded and decoded through a WebRTC connection within this page. No STUN/TURN servers, remote peers, microphone, recording, images, or uploads are used.

Serve this file from http://localhost or http://127.0.0.1 in Chrome or Edge. This checks a browser conferencing pipeline; it does not prove behavior in an actual Meet or Zoom call. Stop releases the camera and both peer connections.

If the camera list is empty or names are hidden, Enable local camera access briefly opens the browser’s default camera to request permission, then immediately stops every track and refreshes the list. It does not start the WebRTC test or request microphone access.
